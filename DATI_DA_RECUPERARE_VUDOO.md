# Dati da recuperare dal Panel Vudoo

## Prodotti — Informazioni di base

Percorso:

```text
Panel Vudoo → Gestione prodotti → Informazioni di base
```

Dati necessari:

- Altezza   
- Lunghezza
- Larghezza
- Aliquota IVA
- `Max_Qty` — quantità disponibile alla vendita - default su 10 unità
- Titolo
- Sottotitolo
- Bullet Points
- Filtri di ricerca

---

## Prodotti — Marketplace

Percorso:

```text
Panel Vudoo → Gestione prodotti → Marketplace
```

Dati necessari:

- Giorni per la spedizione   - default 5 giorni di spedizione 
- Pezzi per confezione   non importa

---

## Produttore / Azienda

Percorso:

```text
Panel Vudoo → Azienda → Configurazione → Informazioni base
```

Dati necessari per creare o associare correttamente il produttore su Base.com:

- Nome produttore
- Foto produttore
- URL / sito web
- Indirizzo
- Codice postale
- Città
- Regione
- Stato / Paese
- Email
- Numero di telefono
